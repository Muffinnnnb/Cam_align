같은 평면을 다시 찾지 않기 — 판정은 그대로, 반복 작업은 줄이기

전체 검사가 끝난 뒤 선택된 촬영쌍을 다시 분석하면서 빈 목록 문구가 표시되던 흐름을 수정했습니다. 완료된 프레임 자체를 화면에 넘겨 곧바로 표시하며, 실제 빈 목록·로딩·실패를 서로 다른 상태로 알립니다.

1. 입력 내용 확인

점군·컬러·원본 거리맵·내부 파라미터의 파일 내용과 거리 범위·점군 모델·프로그램 코드가 같을 때만 저장된 원본 분석을 재사용합니다. 파일명이나 수정 시각만 보고 같은 데이터로 판단하지 않습니다.

2. 무손실 분석 재사용

원본 XYZ·후보 마스크·법선은 NPZ 배열로 값 손실 없이 보관합니다. 메모리는 최근 12개 분석, 디스크 캐시는 최대 1 GiB로 제한합니다. 캐시를 읽을 수 없으면 정상 분석으로 돌아가며 원본은 수정하지 않습니다.

3. RT 판단은 새로

캐시에 넣는 것은 RT와 독립된 검출 결과입니다. RT를 바꾸면 대응·정합·색 투영은 다시 계산합니다. 전체 계산 후 선택 이미지를 표시하기 위해 같은 평면 검출을 한 번 더 실행하지 않습니다.

검출 범위·후보 수·판정 임계값·RANSAC·LM·교차검증을 줄여서 빨라진 것이 아닙니다. 처음 보는 입력은 기존의 전체 분석이 필요하고, RT 재계산 자체도 생략하지 않습니다. 주된 개선 대상은 재검사·재실행·파일 재선택입니다.

동일한 5장을 비교한 분석/로딩 단계: 합계 26.62초 → 0.31초(장당 평균 5.32초 → 0.061초). 후보·학습 입력·투영 XYZ/RGB 값은 정확히 같았습니다. 캐시를 사용한 실제 76장 재검사는 약 6.2초였으며, 최초 분석이나 RT 계산 시간의 단축률로 해석하면 안 됩니다. 측정 조건·94개 단위 테스트·Qt 검증 기록
