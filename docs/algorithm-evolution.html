추가 개선 — 조각의 이름이 아니라 실제 지지영역을 바꾸기

성공 기준은 기존 matched 판정 그대로입니다. 크기·평면 구조·경계 지지·실측 셀·보드 대응 조건을 낮추지 않았고, 부분 대응은 성공 수에 포함하지 않습니다.

여기서 90%는 촬영 76장 중 보드 대응으로 판정된 장수입니다. 각 보드의 픽셀을 90% 이상 복원했다는 뜻이 아닙니다. matched는 기존 구조 검사(크기 70~140%, 실측 셀 점유율 75% 이상 등)와 보드 좌표계의 8×8 셀 커버 60% 이상을 함께 통과해야 합니다. 가림·결손이 없어졌다는 의미도 아닙니다.

1 · 거리 경계로 넓은 후보

좁은 RANSAC 조각만 보던 검출기에, 여러 공간 크기의 거리맵 연속 영역을 추가했습니다. 평활화는 영역 제안에만 쓰고, 법선·치수·PLY는 원본 3D 점으로 계산합니다. RGB 고정 위치 ROI나 선분 기반 법선을 사용하지 않습니다.

2 · 연결된 두 지지영역 재피팅

이웃 실제 점과 공통 평면이 확인된 두 후보를 별도 가설로 재피팅합니다. 손을 거쳐 몸으로 연쇄 병합하지 않습니다. 빈 픽셀에는 점을 만들지 않고, 기존 구조 조건을 다시 모두 검사합니다.

3 · 완전 후보 선택 후 재보정

같은 보드에 더 넓고 조건을 만족하는 후보가 있으면 작은 조각 대신 선택합니다. 개선된 원본 지지영역으로 NSL 치수를 먼저 추정하고, RANSAC + LM 및 시간 구간 제외 RT를 다시 계산합니다.

단계별 확인: v9 57장 → 검출·선택 개선 + 기존 RT 67장 → 새 지지영역으로 치수·RT 재계산 69장. 모든 단계에서 부분 대응을 제외했습니다.

정합 지표의 변화도 구분합니다. 기존 57장의 동일 지지점·시간 구간 제외 모델 비교에서 평면 잔차 중앙값은 17.65 → 15.83 mm로 감소했지만, 영상 경계 오차는 9.43 → 9.77 px, 보드 밖 비율은 3.55 → 4.81%로 소폭 증가했습니다. 보드 대응 수가 늘었다고 모든 RGB 정합 지표가 개선됐다고 보고하지 않습니다.

100% 확장 시험 — 검증된 v10을 유지

부분 대응을 제외한 100%를 목표로 추가 시험했습니다. 그러나 대응 장수 증가와 RT 안정성을 함께 확인하지 못했으므로, 요청한 중단 조건에 따라 69/76장(90.8%)의 기존 v10을 유지했습니다. 100% 달성을 보고하는 내용이 아닙니다.

영역 확장 · 후보 보존

결손을 넘는 영역 제안, 유사 후보의 조기 제거 방지를 시험했으나 69/76장으로 동일했습니다. 별도의 거리 구간 분할은 남은 7장 중 추가 대응 없이 모호한 사례만 늘려 채택하지 않았습니다.

숫자는 70 → 71장까지

원본 후보에 더 엄격한 20 mm 잔차 피팅을 추가한 시험은 기존 RT 기준 71/76장(93.4%)까지 나왔습니다. 부분을 합산한 수치는 아니지만, 측정점을 더 제외한 결과만으로 정확도 향상을 인정하지 않았습니다.

RT 재검증 실패 → 중단

70장·71장 후보 모두 RT 재계산의 첫 번째 시간 구간 분리 검증에서 탈락했습니다. 평면 잔차와 영상 경계 조건을 함께 만족하는 관측이 최소 8개 미만이었습니다. 운영 코드·RT·설정은 교체하지 않았습니다.

최종 유지: v10 · 보드 대응 69장 / 부분 7장. 실패한 시험의 93.4%를 새 성능으로 보고하지 않습니다. 이는 시험한 방법에서 안전한 추가 개선을 확인하지 못했다는 뜻이며, 모든 방법으로 100%가 불가능하다는 증명은 아닙니다.

자세한 범위와 중단 근거: 100% 확장 시험 기록. 기존 7개 모션그래픽과 앞선 개선 이력은 보존했습니다.

달라지지 않은 원칙

보드 대응, RT 학습, RGB 정합은 서로 다른 결과입니다.

보드 일부를 알아봤다고 그 조각의 법선이 RT 학습에 적합한 것은 아닙니다. RANSAC은 잘못된 관측을 제외하고, LM은 남은 관측을 최적화합니다. RGB 융합은 전체 유효 점에 대해 투영·가림을 계산하며 보드 마스크로 색을 강제하지 않습니다.

카메라 사이 거리나 각도를 미리 정하지 않습니다.

추정한 R과 t로 같은 좌표계에 옮긴 뒤 실제 보드 영역과 비교합니다. 카메라가 움직이거나 바뀌면 내부 파라미터 확인과 RT 재보정이 필요합니다. 3픽셀 인접 검사는 NSL 원본 격자의 연결 관계이며 RGB 화면의 고정 위치 ROI가 아닙니다.

90%를 맞추기 위해 정확도 기준을 낮추지는 않았습니다.

v8의 보드 근접폭(대각선의 15%), 근접 점 80%, 내부 비율 65%, 최소 면적 커버 20%는 그대로입니다. v9는 저겹침 후보가 정말 다른 표면인지 추가로 확인합니다. 공통 평면 RMS 20 mm, P90 30 mm 등은 거친 식별용 설계 기준이며 정밀도 보증값이 아닙니다.

다른 환경의 완성도를 아직 보장할 수 없습니다.

다른 배치·RGB 카메라 실측 데이터는 없습니다. 합성 기하 테스트와 현재 76장에 대해서 검증했습니다. 비동기 촬영, ToF 결손, 가림, 잘못된 RT에서는 오대응이나 보류가 발생할 수 있습니다.
