Cam_align — general-purpose metric-neighborhood fallback
2026-10-20 / reference runtime e4b0db3 (v10)

Scope and decision
------------------
Add a source-only 3D neighborhood fallback when the existing image-grid
detector has no structurally eligible candidate. Do not replace successful
hypotheses or change support, identity, RANSAC or LM acceptance thresholds.
No filename exceptions, fixed image-location ROI, RGB/RT-guided point trimming,
checkerboard-shaped missing-data rules, or presumed camera baseline is used.

The capture generator writes Z into PCD intensity when true intensity is absent.
The current recordings therefore cannot be treated as measured reflectance.
An exploratory missing-pixel checkerboard recovery was NOT deployed: it depends
on sensor amplitude settings and material reflectance, not generic XYZ geometry.

Algorithm
---------
nsl_metric_support.py: metric_support(grid, quality_function)
1. Use finite original XYZ in metres; create 10 mm voxel centroids for proposals.
2. Estimate local covariance/normals within 40, 70 and 100 mm neighborhoods.
3. Build a nearby-point graph using normal agreement, local curvature and
   bilateral point-to-local-plane consistency. No reference RT is involved.
4. Propose connected components. Refit final spatial support from original
   measured XYZ via complete_support; voxel means never become exported points.
5. Return only candidates passing ALL existing support_quality conditions.

These are proposal scales suited to the configured 250 x 280 mm board, not
sensor-calibrated noise bounds or universal values for arbitrary object sizes.
The organized-grid completion and existing board-size assumptions remain.
This is a bounded generality improvement, not an unstructured-cloud rewrite.

Additional joint-initialization trial — rejected
-----------------------------------------------
The prior supplemental 20 mm source-refit variant initially showed 71/76 with
the OLD fixed v10 RT, but its recalibration failed a holdout. To investigate
the initialization sensitivity without lowering gates, every one of the eight
polished RANSAC consensuses was passed through the final plane+outline LM;
the best joint consensus was selected, separately within each training fold.
This was an experiment only, not an active-runtime change.

The four folds completed (9/13/27/35 inliers), but the new association outcome
was 69 matched, 6 partial and 1 unconfirmed. One previous matched frame was lost
and one partial recovered. On the SAME 69 original matched source supports,
using each model's time-block-excluded calibration, median errors changed:
  point-plane RMS: 16.4529 -> 18.1066 mm
  bidirectional boundary error: 9.2430 -> 12.9475 px
  fraction outside board: 4.3802 -> 11.0279 percent
This is a measurable regression, so neither the source refit nor multi-start
RT change was deployed. Its trial RT is retained only in the ignored experiment
directory; active v10 RT/settings hashes remain those listed above.
Completing the solver and increasing training inliers (36 -> 39) was NOT used
as proof of better correspondence or RGB alignment.
