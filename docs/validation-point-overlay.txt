Color image point overlay — 2026-10-20

Scope
- Existing NSL -> Color RT, intrinsics, ray correction and occlusion are reused.
- View 2 now overlays the cloud on the RIGHT Color image; the LEFT stays the
  NSL board view. View 3 keeps its plane-error colors.
- Dot/cross glyphs, odd sizes 1..21 native Color pixels (default 3).
- Settings persist automatically; PNG export uses the same glyph settings.
- No change to detection, board identity, calibration, RGB sampling or PLY.
- Enlarged glyphs are display only, not extra points or interpolated depth.

Limitations
- No new calibration accuracy claim; no external-camera validation.
- Color overlay uses distance colors, NOT recoloring of the exported RGB PLY.
- Larger markers can visually cover background pixels around a point. For
  precise alignment inspection use size 1; geometry and visibility are still
  evaluated at the original measured center.
- UI scales the image to its panel, so native-pixel marker sizes scale with it.
- No recomputation of all 76 calibration frames: numerical algorithms unchanged.
