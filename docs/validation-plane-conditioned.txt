Cause and change
----------------
Raw range has a slope on an inclined planar surface. Range-gradient components
can therefore fragment a board, even when the underlying surface is planar.
After the existing range/pair/metric-neighborhood paths have no structurally
eligible candidate, the new fallback forms residual r(p)=n dot p-h using each
independently estimated SOURCE plane. It segments smoothed residual regions,
then reads original finite XYZ again for the final plane/support measurements.

The filter uses no RGB, RT, presumed camera baseline, fixed image ROI, intensity,
checkerboard hole pattern, or frame-specific exception. Missing samples are not
exported or synthesized. No support-quality/association/RANSAC/LM gate is lowered.
It runs only when prior paths fail, so already successful support stays intact.
Existing point-plane RANSAC and linear-loss LM remain unchanged.
