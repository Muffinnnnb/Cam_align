# Cam_align 기술 관련 논문 색인

- 조사일: 2026-09-08
- 분석 대상: `calibrate_d_to_r.py`, `realsense_compare.py`, `calibration_gui.py`
- 범위: Depth(`d`) → 선택한 Target 영상(`r`/color)의 평면 기반 외부 보정, Depth 정렬, 포인트클라우드 저장 및 `rs.align()` 비교
- 보드 설정: 내부 코너 `7 × 8`, 한 칸 `30 mm`, 판 전체 `250 × 280 mm`

이 폴더에는 논문 16편과 RealSense 공식 기술 백서 1편을 저장했다. 모든 PDF는 `%PDF` 헤더, `pdfinfo` 파싱, 암호화 여부, 페이지 수 및 첫 페이지 렌더링을 검사했다. 결과와 SHA-256은 `PDF_검증_SHA256.csv`에 있다.

## 현재 코드의 기술 흐름

| 단계 | 실제 구현 | 관련 문헌 |
|---|---|---|
| 카메라 모델 | 각 폴더의 `Intrinsic.txt`, `Distortion.txt`를 읽고 `undistortPoints`/`projectPoints`로 Brown–Conrady 계열 왜곡을 처리한다. 16-bit Depth에는 scale을 적용해 m 단위로 변환한다. | 01, 09, 10, 11 |
| Target 평면 | `findChessboardCorners` → `cornerSubPix` → `SOLVEPNP_ITERATIVE`로 보드 pose를 구하고 회전행렬의 Z축을 평면 법선으로 사용한다. 30 mm 칸 크기가 metric scale을 만든다. | 01, 12, 13, 14. 02는 PnP 비교 문헌 |
| Depth 평면 | Depth 픽셀을 3D로 역투영하고, 근방의 세 점으로 평면 후보를 무작위 생성한다. inlier 거리, morphology closing, connected component, SVD 재적합, `250 × 280 mm` 크기 prior로 보드 평면을 선택한다. | 03, 04, 05, 15, 17 |
| D → Target RT | 여러 촬영의 평면식 `nᵀx = h`를 대응시켜 `n_t ≈ R n_d`, `h_t ≈ h_d + n_tᵀt`를 푼다. 3개 평면쌍 RANSAC → SVD 회전 → 선형 최소제곱 이동 → LM 비선형 정제를 수행한다. | 03, 05, 06, 07, 08, 14, 15, 16 및 아래의 Zhang–Pless |
| Depth ROI | Target에서 PnP로 얻은 판의 3D 외곽을 기존 RT의 역방향으로 Depth 좌표계에 옮긴 뒤 Depth 영상으로 투영하고, 중심 기준으로 margin만큼 확대한 polygon mask를 만든다. | 01, 06, 08, 15, 16 |
| 픽셀 정렬/PLY | Depth를 3D로 역투영 → RT 적용 → Target 픽셀로 재투영한다. 2×2 splat 후 같은 Target 픽셀에는 가장 가까운 Depth를 남기는 z-buffer를 쓰고 Target 영상으로 point cloud를 채색한다. | 09, 10 |
| `rs.align()` 비교 | RealSense factory intrinsic/extrinsic과 software-device frameset을 이용해 SDK 정렬 결과를 만들고 현재 방식과 PLY/Depth 차이를 저장한다. | 09, 10 및 공식 SDK 링크 |

중요한 구현 구분:

- 전역 RT 정제는 `scipy.optimize.least_squares(..., method="lm")`의 **Levenberg–Marquardt**를 사용한다.
- LM은 선형 손실을 사용하며, 이상치 제거는 앞 단계의 평면쌍 RANSAC이 담당한다.
- 02번 EPnP 논문은 PnP 문제와 대안 solver를 비교하기 위한 문헌이다. 현재 코드는 EPnP를 호출하지 않는다.
- ICP, 원시 스테레오 매칭, Hough/선분 기반 보드 검출, bundle adjustment는 현재 코드에 없다.
